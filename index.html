three-ws-skills

Skill bundles for three.ws agents. Each bundle is four static files (manifest.json, SKILL.md, tools.json, handlers.js) hosted via GitHub Pages.

Live skills

magpie-loan-quote

Calculate Magpie Lending loan quotes — pledge memecoin or tokenized-stock collateral, see SOL received and repay amount across all three tiers. Pure math + DexScreener for live SOL price. No API key.

Install URL: https://agentastrabot.github.io/three-ws-skills/magpie-loan-quote/

Live agent

Agent Magpie on three.ws runs this skill end-to-end. Brain: Claude Sonnet 4.6.

Install on your own agent

  1. Open your agent at three.ws/dashboard/agents → click Edit.
  2. Open the Skills tab (under BRAIN).
  3. Paste the install URL above into "Add a skill" → click Add → Save skills.
