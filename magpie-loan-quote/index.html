magpie-loan-quote

Pure-math skill bundle for quoting Magpie Lending loans on Solana. Two tools: magpie_loan_quote (single tier) and magpie_compare_tiers (all three side-by-side). No API keys required — just DexScreener for live SOL/USD.

Install URL

https://agentastrabot.github.io/three-ws-skills/magpie-loan-quote/

Paste this into your three.ws agent's Skills tab.

Bundle files

  • manifest.json — skill metadata + tool/trigger registry
  • SKILL.md — system-prompt injection that teaches the LLM when to call each tool
  • tools.json — Anthropic-format tool schemas
  • handlers.js — the actual math (runs in a sandboxed Web Worker on three.ws)

Tier rules

TierLTVTermFee
Express30%2 days3%
Quick25%3 days2%
Standard20%7 days1.5%

Math

sol_received = collateral_usd × LTV / sol_price_usd
total_repay  = sol_received × (1 + fee_pct)
liquidation_drop_pct ≈ (1 − LTV × 1.2) × 100

Matches Magpie's published example (pledge 8,000 WIF → receive 3.25 SOL → repay 3.35 SOL at 30% LTV / 3% fee).
